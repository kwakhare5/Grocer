# Legacy Architecture Archive

The files and architecture described here belong to earlier GROCER iterations and are retained only as historical context. They are **not current architecture** and must not be used as implementation guidance.

The current GROCER architecture is defined by `GROCER_V2_MASTER_SPEC.md`, `CONTEXT.md`, `ARCHITECTURE.md`, `AGENTS.md`, and `IMPLEMENTATION_PLAN.md`.

The previous dark-store/operator platform has been split into the companion `Dark-store-operator` repository and must not be reintroduced into GROCER.
